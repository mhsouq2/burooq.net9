How to Configure a UNV Video Intercom System

Wiring, activation, network settings and device linking for a UNV indoor station and door station — with an image for every step.

Quick answer: configuring a UNV intercom is a 10-step process — find all devices, check IP addresses, adjust IPs if needed, log in, configure the door station, configure the indoor station, pair the two, test the call, test door unlock, then connect your mobile phone via EZView or UNV-Link. Most installs take 30–45 minutes once wiring is complete.
📄 Want the exact official screenshots?

This guide is based on Uniview's own official deployment documentation. For the literal interface screenshots (login screen, network settings, device management), see the official Uniview Video Intercom Deployment Guide (PDF).

What you'll need

  • UNV indoor station (e.g. OEI-371S-H-W or similar) and matching door station
  • A PoE switch or PoE injector for power over the network cable
  • A phone or PC on the same local network for initial setup

Step-by-step configuration

  1. Step 1 — Find all devices on the network

    Connect the indoor station, PoE switch, and door station according to the wiring diagram in the box, then power everything on. Use UNV's EZTools desktop application (free from Uniview) to auto-discover every UNV device on your local network — this saves you from hunting for IP addresses manually and is the fastest way to confirm all devices powered on correctly.

  2. Step 2 — Find each device's IP address

    Most UNV door stations and cameras ship with a default static IP in the 192.168.1.x range — check the label on the device itself, or read it directly from the EZTools device list rather than guessing. Note the IP of the indoor station, door station, and any linked cameras before continuing.

  3. Step 3 — Change the IP address (if needed)

    DHCP is enabled by default on the indoor station, assigning an IP automatically. For a permanent installation, switch to a static IP instead so the address never changes after a router restart. Whichever method you use, the door station, indoor station, and any linked network cameras must all sit on the same IP segment (e.g. all starting 192.168.1.x), or the call and live-view functions won't work. This single mismatch causes the majority of "devices won't connect" support calls.

  4. Step 4 — Log in to the door station

    Open a browser and enter the door station's IP address directly (e.g. http://192.168.1.13). Log in with the administrator account. On first login, UNV devices use a default admin password (commonly 123456 on current models — always confirm against your specific unit's quick-start guide, as this can vary by firmware version). Change this immediately.

  5. Step 5 — Configure the door station

    Set the door station's device location (compound/building/unit/room). In multi-unit buildings, this location data is what prevents two apartments' intercoms from cross-linking to the wrong door station. Confirm the door station's protocol/room-number settings match what you'll enter on the indoor station in the next step.

  6. Step 6 — Configure the indoor station

    On the indoor station, follow the first-login wizard: set Wi-Fi (if used), time zone, and the indoor station type (main station or extension). The default location for a main indoor station is District 1, Building 1, Unit 1, Room 1 — update this to match your property's actual numbering.

  7. Step 7 — Pair the door station with the indoor monitor

    From the indoor station's device management screen, use the auto-search function to detect the door station on the network, then add it to the device list. If it isn't found, double check Step 3 — a mismatched IP segment is the most common cause. Network cameras can be added the same way if you want their feed viewable from the indoor station.

  8. Step 8 — Test the call

    Place a test call from the door station to the indoor station and confirm both video and audio work in both directions. Test at least twice from a cold start (door station idle, not already on a call screen) to rule out a one-off glitch.

  9. Step 9 — Configure door unlock

    Confirm the remote door release relay is wired and configured, then test it specifically — a working video call does not guarantee the unlock relay itself is correctly wired. Trigger the unlock from the indoor station during a test call and physically confirm the door latch releases.

  10. Step 10 — Connect to your mobile phone

    Install EZView (Uniview's mobile app) or UNV-Link — Uniview's newer app, which is replacing EZView (EZView service is expected to be phased out by 2027, so UNV-Link is the better long-term choice for new installs). Scan the QR code on the indoor station or door station to bind it to your account, enabling remote call answering and live view from your phone even when you're away.

Expert tips

  • If the door station can't be found during Step 5, it's almost always an IP segment mismatch — recheck Step 3 first before assuming a hardware fault.
  • Use a static IP for any intercom on a permanent installation — a DHCP-assigned address can change after a router reboot and silently break the link between devices.
  • Keep a note of the device location settings (building/unit/room) somewhere accessible — this is the first thing to check if a resident reports "wrong door" video calls.

Common mistakes

  • Skipping the password change — leaving the default admin password active is a real security risk on a device that controls a physical door.
  • Mixed IP segments — the single most common reason a freshly wired system "won't connect."
  • Not testing remote unlock specifically — a working video call doesn't guarantee the door release relay is wired and configured correctly.
