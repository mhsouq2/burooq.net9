How to Configure a UNV Video Intercom System

Wiring, activation, network settings and device linking for a UNV indoor station and door station — with an image for every step.

Quick answer: a UNV intercom is configured in six stages — wire and power on, set the admin password, configure network settings, set the device location, search and add the door station, then test the call and remote unlock. Most installs take 20–30 minutes once wiring is complete.

What you'll need

  • UNV indoor station (e.g. OEI-371S-H-W or similar) and matching door station
  • A PoE switch or PoE injector for power over the network cable
  • A phone or PC on the same local network for initial setup

Step-by-step configuration

  1. Step 1 — Wire and power on the devices

    Connect the indoor station, PoE switch, and door station according to the wiring diagram in the box, then power everything on. The indoor station's home screen appears automatically once powered.

  2. Step 2 — Log in and set the admin password

    On first login, UNV indoor stations use a default admin password (commonly 123456 on current models — always confirm against your specific unit's quick-start guide, as this can vary by firmware version). Change this immediately and set a recovery email if prompted, so you can retrieve the password later if forgotten.

  3. Step 3 — Configure network settings

    DHCP is enabled by default, which assigns the indoor station an IP address automatically. For a permanent installation, switch to a static IP instead so the address never changes after a router restart. Whichever method you use, the door station, indoor station, and any linked network cameras must all sit on the same IP segment, or the call and live-view functions won't work.

    Most UNV door stations and cameras ship with a default static IP in the 192.168.1.x range — check the label on the device or use UNV's EZTools application to auto-discover it on your network rather than guessing.

  4. Step 4 — Set the device location

    Enter the compound/building/unit/room information on the indoor station. This isn't cosmetic — in multi-unit buildings, this location data is what prevents two apartments' intercoms from cross-linking to the wrong door station.

  5. Step 5 — Search and add the door station

    From the indoor station's device management screen, use the auto-search function to detect the door station on the network, then add it to the device list. If it isn't found, double check Step 3 — a mismatched IP segment is the most common cause.

  6. Step 6 — Test the call and remote unlock

    Place a test call from the door station and confirm video, audio, and remote door release all work correctly before finishing the installation. Test at least twice — once with a normal call, and once specifically testing the remote unlock button.

Expert tips

  • If the door station can't be found during Step 5, it's almost always an IP segment mismatch — recheck Step 3 first before assuming a hardware fault.
  • Use a static IP for any intercom on a permanent installation — a DHCP-assigned address can change after a router reboot and silently break the link between devices.
  • Keep a note of the device location settings (building/unit/room) somewhere accessible — this is the first thing to check if a resident reports "wrong door" video calls.

Common mistakes

  • Skipping the password change — leaving the default admin password active is a real security risk on a device that controls a physical door.
  • Mixed IP segments — the single most common reason a freshly wired system "won't connect."
  • Not testing remote unlock specifically — a working video call doesn't guarantee the door release relay is wired and configured correctly.
